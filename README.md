# The Granville Arms — Barford

A responsive, single-page website for The Granville Arms country pub and restaurant in Barford, Warwickshire.

## Included

- Mobile-first responsive layout
- Online table booking links
- Food, drink, garden and events sections
- Telephone, email and Google Maps actions
- LocalBusiness/Restaurant structured data
- Search and social metadata
- Accessible navigation and image descriptions

The production site is contained in `index.html` and can be hosted directly with GitHub Pages.
